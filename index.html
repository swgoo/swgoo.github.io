About Me

I am a researcher bridging deep learning architectures and dynamical systems. My background is in pharmacometrics. This allows me to approach neural network optimization as a continuous, balanced system.
My recent work solves the fundamental instability of Backpropagation Through Time (BPTT) in LLMs. I developed Phasor Memory Networks (PMNet) using unitary phasor dynamics. This breakthrough enables scalable, explicit long-term memory.
Currently, I am expanding these mechanics. My next goal is to build stable models for lifelong learning and memory consolidation.

Research Interests

  • Next-Generation Neural Architectures & Learning Mechanics
  • Stable Backpropagation & Long-Context Explicit Memory
  • Continual Learning & Memory Consolidation Models
  • Dynamical Systems in Deep Learning (Inspired by Pharmacometrics & QSP)
